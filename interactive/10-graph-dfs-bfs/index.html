图、DFS 与 BFS

图题最关键的新增概念只有一个：visited。树通常没有回路，而图可能从 A 走到 B，再走回 A。

统一视角：DFS 用栈（或递归）管理“下一步去哪里”，BFS 用队列管理。其余逻辑通常都是：取出 → 检查 → 标记 → 加入邻居。
01

节点 + 边 = 图

邻接表

graph = {
  'A': ['B', 'D'],
  'B': ['A', 'C', 'E'],
  'C': ['B'],
  'D': ['A', 'E'],
  'E': ['B', 'D']
}

稀疏图最常用邻接表：空间 O(V + E)。矩阵则是 O(V²)。

02

DFS 深入一条路，BFS 一圈圈扩散

DFS：栈 / 递归

从 A 开始。点击一步，观察待办容器。

# DFS（递归）
def dfs(node):
    if node in visited: return
    visited.add(node)
    for neighbor in graph[node]:
        dfs(neighbor)

# BFS（队列）
queue = deque([start]); visited = {start}
while queue:
    node = queue.popleft()
    for neighbor in graph[node]:
        if neighbor not in visited:
            visited.add(neighbor)       # 入队时标记
            queue.append(neighbor)

连通分量与环：不要混淆方向

无向图判断环

DFS 看到已访问邻居不一定是环，它可能只是刚刚走来的父节点。

if visited(neighbor) and neighbor != parent:
    found_cycle = True

有向图判断环

使用三种状态：未访问、正在当前路径中、已经完成。遇到“正在路径中”的节点才是回边。

0 = unvisited
1 = visiting
2 = finished

连通分量的通用计数：遍历所有节点；每次遇到未访问节点，计数 +1，并搜索标记它所在的整个分量。

拓扑排序：先做没有前置条件的任务

有向边 A → C 表示先 A 后 C。入度是一个节点尚未解决的前置条件数量。

Kahn 算法

先把所有入度为 0 的节点入队。

queue = deque(node for node in nodes if indegree[node] == 0)
order = []
while queue:
    node = queue.popleft()
    order.append(node)
    for nxt in graph[node]:
        indegree[nxt] -= 1
        if indegree[nxt] == 0:
            queue.append(nxt)
return order if len(order) == len(nodes) else []  # 否则存在环

clone_map

A → A'B → B'C → C'
copies = {}
def clone(node):
    if node in copies:
        return copies[node]
    copy = Node(node.val)
    copies[node] = copy          # 先登记，防止环导致无限递归
    for neighbor in node.neighbors:
        copy.neighbors.append(clone(neighbor))
    return copy
关键顺序：新节点创建后立刻放入字典，然后才递归邻居。若图里 A → B → A，第二次见到 A 时可以直接返回已有副本。
07

图题四步检查表

1. 节点是谁？

城市、课程、单词、网格格子。

2. 边是什么？

相邻、依赖、可转换关系。

3. 用何种容器？

DFS 栈；最短步数常用 BFS 队列。

4. 何时标记？

BFS 通常在入队时标记，避免重复入队。
