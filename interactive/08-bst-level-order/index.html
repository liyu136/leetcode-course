01

BST 的条件来自所有祖先

“左孩子小、右孩子大”只是表面。真正条件是整棵左子树都小，整棵右子树都大。

局部看似正确，整体可能错误

严格 BST 定义对于每一个节点：左子树的所有值 < 当前值 < 右子树的所有值，并且两棵子树本身也是 BST。

不是普通二叉树的同义词

普通二叉树只限制每个节点最多两个孩子；BST 额外规定值的全局顺序。

重复值能否出现由题目决定。LeetCode 的“验证二叉搜索树”通常要求严格不等。

最常见错误只比较当前节点与直接孩子，会漏掉藏在更深位置、但违反祖先范围的节点。

节点 6 在节点 15 左边

局部检查得到 6 < 15，似乎正确。

但整个节点 15 位于根 10 右侧

因此其中所有值必须大于 10。节点 6 违反来自祖先 10 的下界。

02

搜索不是遍历：每次只走一侧

目标值与当前值比较后，另一整棵子树都可以排除。这正是 BST 提供的信息。

单步搜索

while current is not None:    if target == current.val:        return current    if target < current.val:        current = current.left    else:        current = current.rightreturn None
时间O(h)
迭代空间O(1)
是否固定 O(log n)不是
为什么写 O(h)平衡时高度约为 log n；完全倾斜时高度可能是 n。BST 并不会自动保持平衡。

插入：搜索到空位置，再把新节点接回父节点

def insert(root, value):    if root is None:        return TreeNode(value)    if value < root.val:        root.left = insert(root.left, value)    elif value > root.val:        root.right = insert(root.right, value)    return root

必须写回 root.left 或 root.right。当递归走到空位置时，新节点通过返回值交给父节点，父节点负责把引用接上。

03

中序遍历把树“展开”为递增序列

左子树所有值更小，右子树所有值更大，所以“左—根—右”自然得到从小到大。

中序访问与第 K 小

stack = []current = rootwhile stack or current:    while current:        stack.append(current)        current = current.left    current = stack.pop()    k -= 1    if k == 0:        return current.val    current = current.right
栈中节点的含义已经到达，但它们的值尚未访问；还要先完成各自的左子树。
可以提前停止第 K 个访问节点就是第 K 小，不必先生成完整中序列表。

验证 BST

中序访问值必须严格递增；当前值必须大于上一个值。

第 K 小

中序每访问一个节点令 k -= 1，第一次到 0 时返回。

04

验证 BST：每个节点都有允许区间

范围不是节点自己决定的，而是从所有祖先逐层收紧后传下来。

函数契约validate(node, lower, upper) 判断以 node 为根的整棵子树是否所有值都严格位于开区间 (lower, upper)。

追踪非法树中的区间

if node is None:    return Trueif not (lower < node.val < upper):    return Falsereturn validate(node.left, lower, node.val) \   and validate(node.right, node.val, upper)
根 10：范围 (-∞, +∞)
右孩子 15：范围 (10, +∞)
15 的左孩子 6：范围 (10, 15)
为什么不能只比较 6 与父节点 15？虽然 6 < 15，但它还必须满足祖先 10 传下来的下界。正确条件是 10 < 6 < 15，显然失败。

另一种验证方式：中序严格递增

只保存前一个访问值 previous。如果当前值 <= previous，立即返回 False。初值使用 None 或负无穷，不要随意使用普通数字。

一层开始时记录 level_size = len(queue)。本轮只处理这批节点，期间加入的孩子属于下一层。

07

同名问题，使用的信息完全不同

BST 可以利用大小关系只走一侧；普通树没有大小关系，必须让左右子树把“找到谁”向上传递。

while current:    if p.val < current.val \       and q.val < current.val:        current = current.left    elif p.val > current.val \         and q.val > current.val:        current = current.right    else: return current

第一次出现“两者分居两侧”或“当前节点就是其中一个”时，当前节点就是最近公共祖先。

递归返回值返回当前子树中 p、q 的 LCA；若只找到其中一个，就把那个节点向上传；都没找到则返回 None。
if root is None or root is p \   or root is q:    return rootleft = lca(root.left, p, q)right = lca(root.right, p, q)if left and right: return rootreturn left if left else right
不要混用只有题目明确说明是 BST，才能根据节点值决定搜索方向。普通树的值没有这种含义。

最后整理：结构变化、复杂度与选择方法

BST 题先找有序性，层序题先找“层”，普通树综合题先定义递归返回值。

BST 删除的三种情况

BST 搜索、插入、删除

时间写作 O(h)。平衡时为 O(log n)，完全倾斜时退化为 O(n)。

遍历整棵树

DFS 或 BFS 都要访问每个节点，时间 O(n)。递归空间 O(h)，层序空间 O(w)。
