二叉树进阶模式

真正的难点不是 DFS，而是决定：子树应该返回什么？当前节点又要更新什么？本页用动画把这两件事拆开。

核心句：递归函数是节点向父节点提交的一份“作业”。先定义作业内容，再写代码。
01

平衡二叉树：高度，还是失败信号？

普通求高度只返回整数。平衡判断可以把“不平衡”编码成 -1：一旦子树失败，就一路向上传播，不必重复求高度。

后序计算器

点击下一步，从叶子开始交作业。

def height(node):
    if not node: return 0
    left = height(node.left)
    if left == -1: return -1
    right = height(node.right)
    if right == -1: return -1
    if abs(left - right) > 1: return -1
    return 1 + max(left, right)
02

有序数组建 BST：每次选中点

BST 要保证左小右大；“平衡”要求两边规模接近。因此自然选择区间中点作为根，再递归处理左右区间。

数组 [-10, -3, 0, 5, 9]。注意递归处理的是下标区间，不要反复切片。

def build(left, right):
    if left > right: return None
    mid = (left + right) // 2
    root = TreeNode(nums[mid])
    root.left = build(left, mid - 1)
    root.right = build(mid + 1, right)
    return root
03

前序 + 中序重建：一个负责找根，一个负责切开

前序 preorder

第一个未使用元素就是当前根。

中序 inorder

根左边属于左子树，右边属于右子树。

点击演示递归区间如何缩小。

index = {value: i for i, value in enumerate(inorder)}
pre_i = 0
def build(lo, hi):
    nonlocal pre_i
    if lo > hi: return None
    value = preorder[pre_i]; pre_i += 1
    root = TreeNode(value)
    mid = index[value]
    root.left = build(lo, mid - 1)
    root.right = build(mid + 1, hi)
    return root
前提：节点值互不相同。哈希表让“根在中序中的位置”从 O(n) 查询降为 O(1)。
04

展开为链表：倒着连接更容易

目标顺序是“根 → 左 → 右”。如果按反向的“右 → 左 → 根”遍历，每次只需把当前节点的 right 指向上一个处理好的节点。

处理顺序：6, 5, 4, 3, 2, 1。链表会从头部逐步长出来。

previous = None
def dfs(node):
    nonlocal previous
    if not node: return
    dfs(node.right)
    dfs(node.left)
    node.right = previous
    node.left = None
    previous = node
05

路径总和 III：树上的前缀和

到当前节点的路径和为 current。若祖先路径中出现过 current - target，中间那一段的和就恰好是 target。

沿路径进入与退出

示例路径 10 → 5 → 3，target = 8。

prefix = {0: 1}
def dfs(node, current):
    if not node: return 0
    current += node.val
    answer = prefix.get(current - target, 0)
    prefix[current] = prefix.get(current, 0) + 1
    answer += dfs(node.left, current) + dfs(node.right, current)
    prefix[current] -= 1       # 离开当前路径：撤销现场
    return answer
为什么要回溯？prefix 只允许包含“当前根到当前节点”这条路径。离开节点若不减一，兄弟分支会错误地互相借用记录。
06

最大路径和：返回值与全局答案不是同一件事

交给父节点

父节点只能选择左边或右边的一条链：

node.val + max(left, right)

更新全局答案

路径可以在当前节点拐弯，同时接上两边：

node.val + left + right

示例：节点 20，左侧贡献 15，右侧贡献 7。

best = float('-inf')
def gain(node):
    nonlocal best
    if not node: return 0
    left = max(gain(node.left), 0)
    right = max(gain(node.right), 0)
    best = max(best, node.val + left + right)
    return node.val + max(left, right)
