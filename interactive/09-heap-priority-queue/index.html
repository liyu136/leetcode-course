堆与优先队列

堆不是完整排序。它只维持一个承诺：堆顶永远是当前最小值（或最大值），插入和取出都只需 O(log n)。

判断信号：题目反复出现“当前最小”“第 k 大”“前 k 个”“从若干候选中选最优”，优先考虑堆。
01

为什么不每次排序？

完整排序

一次排序 O(n log n)，你知道所有元素的先后顺序。

信息很全，但许多 Top K 题根本用不到。

大小为 k 的堆

扫描 n 个元素，每次维护 O(log k)。

只保存真正可能进入答案的 k 个候选。

03

插入上浮，弹出下沉

初始小顶堆 [2, 5, 4, 9, 7]，准备插入 1。

heappush

先放在数组末尾，再与父节点比较；更小就交换，直到满足堆序。

heappop

取走堆顶，把末尾放到顶部；再与较小的孩子交换，直到满足堆序。

04

Python 的 heapq

import heapq

heap = []
heapq.heappush(heap, 5)
heapq.heappush(heap, 2)
smallest = heapq.heappop(heap)  # 2

# 最大堆：存相反数
heapq.heappush(heap, -10)
largest = -heapq.heappop(heap)

# 元组先比较 priority，再比较 value
heapq.heappush(tasks, (priority, task_id, task))
常见坑：元组第一项相同时，Python 会继续比较第二项。若第二项是不可比较的对象，加入唯一编号 task_id 作为稳定的打破平局字段。
05

第 k 大：保存“最大的 k 个”

使用大小为 k 的小顶堆。堆顶正好是这 k 个大数里最小的，也就是整体第 k 大。

nums = [3,2,1,5,6,4], k = 2

逐个读数。超过 k 个时，弹出最小值。

heap = []
for x in nums:
    heapq.heappush(heap, x)
    if len(heap) > k:
        heapq.heappop(heap)
return heap[0]

合并 K 个有序序列：只放每条队伍的队首

堆里只需要 K 个候选，而不是把所有元素一次性倒进去。

# (值, 来自第几条序列, 在该序列的位置)
heap = [(seq[0], i, 0) for i, seq in enumerate(sequences) if seq]
heapq.heapify(heap)
while heap:
    value, row, col = heapq.heappop(heap)
    answer.append(value)
    if col + 1 < len(sequences[row]):
        nxt = sequences[row][col + 1]
        heapq.heappush(heap, (nxt, row, col + 1))
