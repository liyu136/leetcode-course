双指针

双指针能把许多 O(n²) 枚举降为 O(n)，靠的不是魔法，而是数组的顺序或题目中的单调关系。

每次移动前都问：我为什么能确定被跳过的组合不可能成为答案？如果答不出来，移动规则可能只是猜测。
01

三种常见姿势

相向

left → ← right

回文、排序数组两数之和、盛水、三数之和。

同向

slow → fast →

移动零、原地去重、滑动窗口。

两条序列

i → / j →

合并有序数组、求交集、比较序列。

02

回文：比较最外层，再向内收缩

字符串 “racecar”。左右字符相等，才有必要继续看里面。

left, right = 0, len(s) - 1
while left < right:
    if s[left] != s[right]:
        return False
    left += 1
    right -= 1
return True
03

有序两数之和：一次排除一整行组合

和太小，只能增大较小数，所以移动 left；和太大，只能减小较大数，所以移动 right。这依赖数组已经排序。

target = 9

从最小值和最大值开始。

证明 left 可以丢掉：若 nums[left] + nums[right] < target，那么 left 与任何不超过 right 的数相加都更小，因此 left 不可能参与答案。
04

盛最多水的容器：移动短板

面积 = 宽度 × min(左高, 右高)。宽度每次都会减小；只有移动短板，才有可能用更高的板补偿宽度损失。

height = [1,8,6,2,5,4,8,3,7]

best = 0

为什么不能移动长板？宽度变小，短板不变，面积上限只会更小；它不可能得到更优答案。
05

移动零：fast 负责读，slow 负责写

nums[:slow] 始终表示“已经整理好的非零区域”。fast 扫描新元素，遇到非零就写到 slow 所在位置。

nums = [0,1,0,3,12]。R 是读取位置，W 是下一个非零数应放的位置。

slow = 0
for fast in range(len(nums)):
    if nums[fast] != 0:
        nums[slow], nums[fast] = nums[fast], nums[slow]
        slow += 1
循环不变量：每轮开始时，[0, slow) 已经是处理过部分中的所有非零元素，顺序不变。

两条有序序列与三数之和

两个数组求交集

i = j = 0
while i < len(a) and j < len(b):
    if a[i] == b[j]:
        answer.append(a[i]); i += 1; j += 1
    elif a[i] < b[j]: i += 1
    else: j += 1
较小的一方不可能与对方当前及之后的更大元素相等，因此安全前进。
