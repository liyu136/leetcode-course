二叉树不是“很多箭头”

它是一种递归结构：一个节点，加上两棵规模更小、结构完全相同的树。

从任意节点重新看，仍然是一棵树

整棵树：根是 1，左子树以 2 为根，右子树以 3 为根。

节点里保存什么？

class TreeNode:    def __init__(self, val=0,                 left=None, right=None):        self.val = val        self.left = left        self.right = right

left 和 right 保存的是对其他节点的引用，也可能是 None。

最重要的递归视角假设左右子树的问题已经解决，当前节点怎样用它们的结果得到整棵树的答案？
不要试图一眼看完整棵树先只看当前节点，再把左子树、右子树当作两个规模更小的同类问题。

术语不是重点，但必须能定位

根与子树

1 是根；以 2 为根的完整部分叫左子树。

叶节点

3、4、5 没有孩子，因此是叶节点。

深度与高度

深度从上往下定位节点；高度从当前节点向下看最深路径。单位可能按边或节点，必须看题目。

递归不是瞬间得到答案

每次函数调用都会暂停在自己的位置，等待更小问题返回；这些暂停的调用保存在调用栈中。

函数契约max_depth(node) 返回“以 node 为根的树的最大节点层数”。空树返回 0。

03

三种 DFS，只差“何时访问根”

递归结构完全相同；把处理当前节点的那一行放在左递归之前、中间或之后，就得到三种顺序。

前序：根左右

先处理当前节点，再进入孩子。适合复制树、向下传递状态、先做操作再递归。

中序：左根右

在左右子树之间处理根。二叉搜索树的中序遍历会得到有序序列。

后序：左右根

先取得左右子树结果，再处理当前节点。高度、直径等题最常用。

04

两种递归：记录访问 vs 返回答案

很多“会想但写不出”的根源，是没有提前说清函数到底返回什么。

遍历型：用外部列表收集

result = []def dfs(node):    if node is None:        return    result.append(node.val)    dfs(node.left)    dfs(node.right)

目标是“访问每个节点并记录”。递归调用主要产生动作，不需要组合返回值。

分解型：每次返回明确结果

def max_depth(node):    if node is None:        return 0    left = max_depth(node.left)    right = max_depth(node.right)    return 1 + max(left, right)

目标是“求一个答案”。左右子树先返回局部答案，当前节点再组合。

写代码前，先填这四个空

① 输入
函数处理的是以 node 为根的哪一棵子树？
② 返回值
返回的是高度、是否满足条件、节点，还是别的东西？必须是一句话能说清的定义。
③ 空树
什么值能让后续递推成立？求深度返回 0，判断路径和通常返回 False；没有统一模板。
④ 组合
当前节点如何使用左、右递归结果？例如 1 + max(left, right)。

把递归当成数学递推

D(T) = 0（空树）
D(T) = 1 + max(D(T.left), D(T.right))（非空树）

你不需要在脑中同时跟踪全部调用。相信契约：D(T.left) 会正确给出左子树深度，然后只负责当前这一层。

05

翻转、相同与对称

这三类题都在同时观察左右子树，但“左右如何配对”不同。

逐节点翻转二叉树

if root is None:    return Noneroot.left, root.right = \    root.right, root.leftinvert_tree(root.left)invert_tree(root.right)return root
先交换后递归时要跟着新方向走交换后，root.left 已经是旧的右子树。代码仍然正确，因为最终每个节点都会被访问一次。

两棵树相同

配对方向相同：

p.left ↔ q.left
p.right ↔ q.right

都空为 True；只有一个空为 False；都非空时比较值和两对同向子树。

两棵树互为镜像

配对方向交叉：

left.left ↔ right.right
left.right ↔ right.left

“对称”不是左右子树完全相同，而是沿中轴镜像。

边界判断为什么必须分三层？

  1. 两个节点都为空：这一对匹配成功；
  2. 只有一个为空：结构不同；
  3. 两个都非空：才可以安全访问 .val 并继续递归。

07

直径：返回一种信息，顺便更新另一种

父节点只需要子树高度；但全局答案需要检查每个节点处“左高度 + 右高度”。

后序计算高度，同时更新 best

当前节点—
返回高度—
全局 best（边数）0
def diameter(root):    best = 0    def height(node):        nonlocal best        if node is None:            return 0        left = height(node.left)        right = height(node.right)        best = max(best, left + right)        return 1 + max(left, right)    height(root)    return best

height 返回

一条能够接到父节点的、向下延伸的最长路径。

best 保存

任意节点处，把左、右两条路径连接起来得到的最大边数。

为什么直径不一定经过整棵树的根？最长路径可能完全位于某棵深层子树内。因此每个节点都要尝试成为路径的“最高连接点”。
08

迭代 DFS：把调用栈摆到桌面上

递归由 Python 替你维护栈；迭代写法则由你显式地压入和弹出节点。

前序遍历的显式栈

stack
result
stack = [root]while stack:    node = stack.pop()    result.append(node.val)    if node.right:        stack.append(node.right)    if node.left:        stack.append(node.left)
为什么先压右、再压左？栈是后进先出。左节点后入栈，下一轮才会先弹出左节点，从而得到“根、左、右”。
什么时候更适合迭代？树可能极深、担心 Python 递归深度限制，或者题目明确要求不用递归时。
09

最后把模式压缩成检查表

树题的代码不需要靠灵感：函数契约、空树、递归顺序和返回值可以逐项确定。

时间复杂度

访问每个节点一次的 DFS 通常为 O(n)。不要因为有两次递归调用就误判为 O(2ⁿ)：左右子树的节点集合通常不重叠。

空间复杂度

递归栈空间是 O(h)。平衡树高度约为 O(log n)；完全倾斜的树高度可达 O(n)。
