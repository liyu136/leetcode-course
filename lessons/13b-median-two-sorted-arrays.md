# 第 13b 讲：二分分割——两个有序数组的中位数

## 0. 这道题为什么需要单独一讲

普通二分是在一个有序序列中找数或边界。这道题二分的不是某个数，而是：

```text
第一个数组在什么位置切开
```

切开后，再由总长度确定第二个数组的切分位置。目标是让左半部分包含整体较小的一半元素，右半部分包含较大的一半。

这是 Hot 100 中技巧性很强的困难题。第一次学习时，应先掌握合并两个数组的 `O(m+n)` 方法，再理解这里的 `O(log(min(m,n)))` 解法。

---

## 1. 把中位数改写成分割问题

设两个有序数组为 `a` 和 `b`，长度分别为 `m` 和 `n`。选择切分位置：

```text
a 左边有 i 个元素
b 左边有 j 个元素
```

要求左半部分元素数量为：

```text
half = (m + n + 1) // 2
```

因此：

```text
j = half - i
```

多出来的 `+1` 让总长度为奇数时，左半部分比右半部分多一个元素，中位数就是左半部分最大值。

---

## 2. 正确分割的两个条件

定义四个边界：

```text
a_left  = a[i-1]    a_right = a[i]
b_left  = b[j-1]    b_right = b[j]
```

正确分割必须满足：

```text
a_left <= b_right
b_left <= a_right
```

因为只有这样，左半部分所有元素才都不大于右半部分所有元素。

数组边缘使用无穷哨兵：

```text
i == 0 时 a_left  = -∞
i == m 时 a_right = +∞
```

这比为每种空半区写独立分支更清晰。

---

## 3. 为什么只在较短数组上二分

令 `a` 始终为较短数组：

```python
if len(a) > len(b):
    a, b = b, a
```

这样 `i` 在 `[0, m]` 内变化时，由 `j = half - i` 得到的 `j` 能保持在合理范围，而且复杂度取决于较短数组长度。

若短数组为空，哨兵规则也能自然处理。

---

## 4. 二分移动依据

如果：

```text
a_left > b_right
```

说明 `a` 左半部分放入了过大的元素，`i` 应该减小。

否则如果：

```text
b_left > a_right
```

说明 `a` 左半部分元素太少，`i` 应该增大。

这就是二分所需的单调方向。

---

## 5. 完整代码

```python
def find_median_sorted_arrays(a, b):
    if len(a) > len(b):
        a, b = b, a

    m, n = len(a), len(b)
    half = (m + n + 1) // 2
    low, high = 0, m

    while low <= high:
        i = (low + high) // 2
        j = half - i

        a_left = float('-inf') if i == 0 else a[i - 1]
        a_right = float('inf') if i == m else a[i]
        b_left = float('-inf') if j == 0 else b[j - 1]
        b_right = float('inf') if j == n else b[j]

        if a_left > b_right:
            high = i - 1
        elif b_left > a_right:
            low = i + 1
        else:
            if (m + n) % 2 == 1:
                return max(a_left, b_left)

            left_max = max(a_left, b_left)
            right_min = min(a_right, b_right)
            return (left_max + right_min) / 2
```

题目保证输入有效且两个数组不会同时为空，因此循环必然能找到正确分割。

---

## 6. 正确性理解

分割位置正确时：

1. 左右元素数量符合中位数定义；
2. 左半部分最大值不超过右半部分最小值；
3. 奇数长度时，左侧多出的那个最大值就是中位数；
4. 偶数长度时，中位数是左侧最大值与右侧最小值的平均值。

我们不需要知道左右半部分内部的完整合并顺序，只需要四个边界值。

时间为 `O(log(min(m,n)))`，额外空间 `O(1)`。

---

## 7. 常见错误

1. 没有保证在较短数组上二分。
2. `half` 忘记加一，导致奇数长度处理复杂。
3. 混淆切分位置 `i` 与元素下标 `i`。
4. 访问 `a[i-1]` 或 `a[i]` 时没有处理边界。
5. `a_left > b_right` 时错误地向右移动。
6. 偶数长度只取左侧最大值，没有与右侧最小值求平均。

## 8. 本讲总结

- 本题二分的是分割位置，而不是目标数。
- 一个数组的切分位置确定后，另一个由左侧总数量唯一确定。
- 正确性只依赖四个边界值。
- 这是高级二分模式，不应替代更基础的合并思路学习。
