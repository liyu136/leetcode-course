# 第 14b 讲：贪心算法——只保留对未来最有利的状态

## 0. 贪心不是“每次选最大的”

贪心算法在每一步保留一个局部最优状态，希望它足以构造全局最优答案。

真正的难点不是代码，而是证明：

```text
放弃其他状态不会损失最终最优解
```

常见证明方式：

1. 领先法：当前状态始终不比任何其他方案差；
2. 交换论证：任意最优方案都能交换成贪心选择而不变差；
3. 覆盖范围：只保留能覆盖最远位置的方案；
4. 状态支配：一个状态在所有未来选择中都不可能优于另一个状态。

---

## 1. 买卖股票的最佳时机

只能买卖一次，买入必须发生在卖出之前。

扫描到今天时，若今天卖出，最好搭配此前最低价格买入。因此只需保存：

```text
min_price：此前最低价格
best：目前最大利润
```

```python
def max_profit(prices):
    min_price = float('inf')
    best = 0

    for price in prices:
        min_price = min(min_price, price)
        best = max(best, price - min_price)

    return best
```

更高的历史买入价永远不会比最低价更好，因此可以永久丢弃。

不要简单地用 `max(prices) - min(prices)`，因为最低价格可能出现在最高价格之后。

## 2. 跳跃游戏：维护最远可达位置

`nums[i]` 表示从位置 `i` 最远可以跳多少步。

```python
def can_jump(nums):
    farthest = 0

    for i, jump in enumerate(nums):
        if i > farthest:
            return False
        farthest = max(farthest, i + jump)

    return True
```

循环不变量：扫描到 `i` 之前，`[0, farthest]` 内的所有位置都属于当前可达覆盖范围。

我们不关心具体怎样跳到每个位置，只关心所有方案中能覆盖到的最远边界。

---

## 3. 跳跃游戏 II：像 BFS 一样按层扩大边界

目标是最少跳跃次数。维护：

- `current_end`：使用当前跳数能到达的最远边界；
- `farthest`：在当前层所有位置中，再跳一步能到达的最远位置。

```python
def jump(nums):
    jumps = 0
    current_end = 0
    farthest = 0

    for i in range(len(nums) - 1):
        farthest = max(farthest, i + nums[i])

        if i == current_end:
            jumps += 1
            current_end = farthest

    return jumps
```

它与 BFS 分层相似：当前覆盖区间是这一层；扫描完这一层后，才把跳数加一并进入下一层。

循环只到 `n-2`，因为到达最后一个位置后不应再增加一次跳跃。

## 4. 划分字母区间

要求把字符串切成尽可能多的片段，使每个字母最多出现在一个片段中。

先记录每个字符最后出现的位置。扫描当前片段时，片段右边界必须覆盖其中所有字符的最后位置：

```python
def partition_labels(s):
    last = {char: i for i, char in enumerate(s)}
    answer = []
    start = 0
    end = 0

    for i, char in enumerate(s):
        end = max(end, last[char])

        if i == end:
            answer.append(end - start + 1)
            start = i + 1

    return answer
```

当 `i == end` 时，当前片段内见过的所有字符都不会在后面再次出现，因此现在切开是合法的。为了得到最多片段，应在第一次合法时立即切开。

## 5. 贪心与动态规划怎样区分

### 贪心

过去的详细选择可以压缩成一个不会吃亏的最优状态。例如：

- 最低买入价；
- 最远可达位置；
- 当前层下一步最远边界。

### 动态规划

未来结果依赖多个不可互相支配的子状态，需要保存它们的答案。例如打家劫舍必须比较“抢当前”与“不抢当前”。

如果无法证明局部状态支配其他选择，不要仅凭直觉使用贪心。

---

## 6. 一个通用思考框架

面对可能的贪心题，依次写下：

```text
候选状态是什么？
哪一个状态对所有未来决策都不差？
为什么其他状态可以永久丢弃？
每一步维护的覆盖范围或最优边界是什么？
```

代码写完后，尝试构造反例。特别检查：

- 局部最大是否会堵死未来；
- 当前最便宜是否发生在合法时间之前；
- 边界更新是否混入了下一层的信息；
- 输入含负数时，所谓“越大越好”是否仍成立。

---

## 7. 常见错误

1. 把贪心理解成“每轮选择数值最大项”。
2. 没有说明为什么被丢弃的状态永远不会更好。
3. 股票题忽略买卖先后顺序。
4. 跳跃游戏访问了尚不可达的位置。
5. 跳跃游戏 II 每扫描一个位置就增加跳数。
6. 划分字母区间只看当前字符，没有扩大到片段内其他字符的最后位置。

## 8. 本讲检查表

1. 我的贪心状态具体表示什么？
2. 它是否对所有未来选择都至少不差？
3. 能否用领先法、覆盖范围或交换论证解释正确性？
4. 什么时候提交一次答案或进入下一阶段？
5. 是否存在简单反例推翻当前选择？

## 9. 本讲总结

- 贪心的核心是状态支配，不是凭感觉选最大值。
- 股票题保留最低历史价格。
- 跳跃游戏保留最远覆盖边界。
- 最少跳跃通过当前层与下一层边界计数。
- 划分区间在最早合法位置切开。
- 无法证明局部选择不会吃亏时，应考虑 DP、搜索或其他方法。
